# 备案号填写指引（公安联网备案 / ICP）

> 用途：公安联网备案、ICP 备案**审核通过后**，把备案号填进系统，官网 / 管理后台 / 商家 H5 / 小程序**一处填写、四端自动生效**。
> 前提：本准备版本已上线（后端 `/api/filing` 接口 + 四端展示位就绪）。未填号前，各端备案位自动隐藏，不显示占位文字。

## 一、什么时候填

- ICP 备案号：工信部（管局）审核通过、拿到备案号后填。
- 公安备案号：在全国互联网安全管理服务平台（`beian.mps.gov.cn`）完成公安联网备案、拿到"公网安备"号后填。
- 两个号互不依赖，先拿到哪个先填哪个。

## 二、填写入口（后台管理页）

进入管理后台 → **内容与运营** → **文案配置** → 找到 **「备案信息」** 分组，共 3 个字段：

| 字段 | 后台显示名 | 填什么 | 示例 |
| --- | --- | --- | --- |
| `filing.icpNo` | ICP 备案号 | 管局下发的完整备案号 | `湘ICP备2026000123号` |
| `filing.policeNo` | 公安备案号 | 公安下发的完整备案号 | `湘公网安备 43090002001234号` |
| `filing.policeLink` | 公安备案查询链接 | 公安下发的完整查询 URL（一般留空即可，见下） | `https://beian.mps.gov.cn/...` |

填完保存即生效，无需发版、无需重启。

## 三、三个字段的填写要点

1. **ICP 备案号（`filing.icpNo`）**
   - 照抄管局短信/后台里的完整号，包含省份简称与"ICP备"字样。
   - 查询链接系统固定指向工信部 `https://beian.miit.gov.cn/`，不用填。

2. **公安备案号（`filing.policeNo`）**
   - 照抄公安平台下发的完整号，形如 `X公网安备 XXXXXXXXXXXX号`。
   - 系统会**自动从号码里提取连续数字**作为 recordcode，拼出官方查询链接：
     `https://beian.mps.gov.cn/#/query/webSearch?recordcode=XXXXXXXXXXXX`

3. **公安备案查询链接（`filing.policeLink`)**
   - **一般留空**。留空时走上面第 2 条的自动拼接，够用。
   - 只有公安机关明确下发了一个**指定的完整查询 URL** 时才填，且必须以 `https://` 或 `http://` 开头。
   - 填了非法链接（非 http）系统会忽略并回落到自动拼接，防止注入。

## 四、四端展示位置与效果

| 端 | 位置 | 展示内容 | 点击行为 |
| --- | --- | --- | --- |
| 官网 `/site/index.html` | 页脚底部 | ICP 备案号 + 公安备案号 | 新窗口打开官方查询页 |
| 管理后台 `/admin.html` | 左侧栏底部 | ICP 备案号 + 公安备案号 | 新窗口打开官方查询页 |
| 商家 H5 `/merchant.html` | 登录页卡片底部 + "我的"页底部 | ICP 备案号 + 公安备案号 | 新窗口打开官方查询页 |
| 小程序"我的"页 | 页面底部（技术支持署名上方） | ICP 备案号 + 公安备案号 | 点击复制备案号（小程序内无法直开外部链接） |

- 任一字段留空 → 该项不显示；两个都留空 → 整块备案区隐藏。
- 小程序端文案从接口实时读取（60 秒缓存），**填号后无需重新提交小程序审核**。

## 五、数据来源与实现（技术备查）

- 后端：
  - `src/domain/content.js`：`CONTENT_DEFS` 的「备案信息」分组（3 个白名单字段）；`filingInfo(db)` 生成结构化数据（自动提取 recordcode、链接校验、留空返回 null）。
  - `src/routes/public.js`：`GET /api/filing` 公开只读接口。
- 前端：
  - `public/js/filing-badge.js`：三端 HTML 共用渲染脚本，数据源 `/api/filing`，"有值才显示"。
  - 小程序 `pages/profile/profile.js` 的 `loadFiling()` + `pages/profile/profile.wxml` 的备案块。
- 测试：`test/filing.test.js`（7 项，覆盖白名单 / 留空 / 链接拼接 / 注入回落 / 清空回退）；后端全套 428/428 通过。

## 六、合规提醒

- 公安联网备案要求网站在**开通后 30 日内**办理，且备案号须在网站首页底部**可见**——官网页脚已就位，填号后即满足。
- 公安备案数据码**有效期 30 天**，拿到后尽快在 `beian.mps.gov.cn` 完成备案，过期需重新走同步。
- 备案信息如有变更（主体、域名、负责人），需同步更新备案号或查询链接，本系统只需改文案配置即可。
