## 二、环境变量（生产必配，缺一拒绝启动 / 功能降级）

| 变量 | 用途 | 缺失后果 |
|------|------|---------|
| `NODE_ENV=production` | 生产模式开关 | 守卫不生效，禁止上线 |
| `ADMIN_PASSWORD` | 管理员口令（≥12 位，含大小写字母+数字） | **服务拒绝启动** |
| `ADMIN_USER` | 管理员账号名 | 回落默认值 admin |
| `WX_APPID` | 小程序 AppID（登录 + 支付 + 转账共用） | 登录降级为开发态 |
| `WX_SECRET` | 小程序 Secret（code2session 真实登录） | 登录降级为开发态 |
| `WX_MCHID` | 微信支付商户号 | **服务拒绝启动**（支付守卫） |
| `WX_MERCHANT_SERIAL` | 商户证书序列号 | 同上 |
| `WX_PRIVATE_KEY` | 商户 API 私钥 | 同上 |
| `WX_APIV3_KEY` | APIv3 密钥（回调解密/商家转账） | 回调无法解密 |

可选：

- [ ] `PORT`（默认 3000）
- [ ] `TRUST_PROXY=1`（Nginx/SLB 反代后必须开启，否则限流/上传 IP 识别失真）
- [ ] `BAFANGJU_DB_PATH`（默认 `data/bafangju.db`）
- [ ] `BAFANGJU_UPLOAD_DIR` / `BAFANGJU_UPLOAD_PRIVATE_DIR`（默认 `data/uploads` / `data/uploads-private`）
- [ ] 口令与密钥**不写进 ecosystem.config.js**，用系统环境变量或 PM2 env 文件注入
