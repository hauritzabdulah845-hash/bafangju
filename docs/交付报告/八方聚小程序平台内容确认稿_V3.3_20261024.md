## 一、项目概述

### 1.1 项目背景

实体门店存在大量本来就要发生的消费，但线上线下割裂，商家缺乏跨店引流工具，用户缺乏持续复购理由，平台缺乏可结算的真实收益来源。本平台通过异业联盟整合粮油食品、健康专区、美容美发、休闲娱乐、五金建材、餐饮美食、酒店民宿等实体商家，以商家定位、优惠券、广告位、商品展示和阶梯返还机制，将实体店真实消费、广告收益与用户贡献挂钩，形成"下单—阶梯降价—复购进度—免单—复购—商家核销—真实收益分配"的闭环。

### 1.2 项目目标

1. 用户端：让用户 3 秒看懂"买得越多付得越少、第 n 单免单、复购进度随时可见"（阶梯按类目可分配利润率动态生成，r=20% 即 6 步；页面阶梯表按用户当前进度与目标商品动态生成，示例基准见 §4.6），随时查看返还、进度、复购与分红情况。
2. 商家端：让实体店可入驻、定位展示、发券、购买广告位、上传商品、核销和对账。
3. 平台端：可配置分佣、类目利润率与阶梯参数、贡献值、等级、广告任务、提现、风控、排队分红和季度分红。
4. 联盟端：通过微信流量主广告组件与异业优惠券形成跨店流量与真实广告收益。
5. 合规端：所有分佣、分红均来自真实可分配收益；返还为价格内嵌优惠，不形成刚性兑付、资金池和应付负债。

### 1.3 成功指标

| 指标                    | 目标     |
| --------------------- | ------ |
| 首页到下单转化率              | ≥8%    |
| 周期完成率（完成 n 单用户/首单用户）  | ≥25%   |
| 免单达成率（达成免单用户/进入周期用户）  | ≥15%   |
| 返还触发后 7 日复购率          | ≥35%   |
| 首期商家入驻数               | ≥100 家 |
| 广告/站内任务完成率            | ≥60%   |
| 排队分红日发放成功率            | ≥98%   |
| 排队分红顺延率（顺延发放日/应发放日）   | <5%    |
| 提现成功率                 | ≥98%   |
| 投诉率                   | <1%    |

### 1.4 技术实现边界说明（V3.2 新增）

以下能力受微信平台规则约束，方案按边界设计（详细见 §12）：

1. 微信支付最低 0.01 元：第 n 单免单以"免单订单"形式实现，不走支付通道。
2. 微信服务商分账上限 30%：分佣不走分账，采用收益账户记账结算 + 商家转账提现。
3. 长期订阅消息不可用（电商类目）：一次性订阅 + 站内消息中心。
4. 第三方广告联盟 JS SDK 不可在小程序内运行：微信流量主组件 + 站内任务系统。
5. 商家转账有限额与开通门槛（90 天交易记录）：上线初期收益可累计、提现通道预计在支付跑通约 3 个月后开通，需甲方知晓并纳入排期。

### 2.2 非目标

1. 不做金融理财、不做刚性兑付、不做资金池。
2. 不做多层级团队计酬，不以人数直接发钱。
3. 不做诱导点击、刷量广告和虚假交易。
4. 不替代商家自有收银系统，平台聚焦联盟引流、券核销、广告和阶梯返还。
5. 不做以用户货款或后续订单为资金来源的"排队返利"（即以后到用户的订单资金返还先到用户）；阶梯返还按**本人**复购进度定价（第 n 单免单），排队分红仅分配分佣后的平台真实利润，两者资金严格隔离（详见 §4.6、§4.12）。
6. 不接入第三方广告联盟 JS SDK（微信小程序平台限制），联盟广告收益以微信流量主结算与异业商家广告位费用为准。

## 四、业务模型与核心规则

### 4.1 业务闭环

```text
用户扫码/分享 → 绑定关系 → 首页看模式（阶梯降价、第 n 单免单）→ 下单 → 支付成功
→ 按阶梯价实付，计入本人类目复购进度 → 完成第 n 单免单（免单订单，免单 1 件）
→ 周期重置、循环 → 我的返还/复购进度中心/复购中心/我的分红/消息中心提醒
→ 复购 → 商家核销/发货
→ 真实商品毛利/商家服务费/广告收益进入可分配池
→ 按分佣基数记入各角色收益账户，平台实收进入排队分红池按队列发放
→ 提现（商家转账）/对账/风控
```

### 4.2 收益来源

1. 商品毛利与服务费。
2. 商家入驻服务费、优惠券服务费、核销服务费。
3. 商家广告位费用。
4. 微信流量主广告分成收益。
5. 其他经合规评审的真实服务收入。

### 4.3 资金分配口径

```text
可分配收益   = 订单实付金额 - 商品成本 - 税费 - 支付通道费
             - 退款金额 - 优惠金额 - 平台基础运营成本
可分配利润率 r = 可分配收益 ÷ 商品标价（按类目/单品在后台配置）
（免单订单无可分配收益，不参与分佣与入池）

阶梯返还设计（按 r 动态配置，n = ⌈1/r⌉ + 1，向上取整）：
  返还单数 n：r=20% → 6 单、25% → 5 单、33.3% → 4 单、50% → 3 单
  步长 = 商品标价 ÷ (n - 1)（r 倒数为整数时恰为"标价 × r"，即一单利润）
  第 k 单实付 = 商品标价 - (k-1) × 步长；第 n 单实付 0 元（免单订单）
  示例（10 元商品、r=20%、n=6）：10 / 8 / 6 / 4 / 2 / 0，合计实付 30 元
  第 n+1 单起循环，回到商品标价

分佣基数   = 可分配收益（按单计算，为负记 0；不再计提返还拨备）
排队分红池 = 分佣后的平台实收 = 平台服务费 + 间推关闭份额（独立核算，见 §4.12）
```

规则：

1. **阶梯价即返还**：返还以"后续订单降价 + 第 n 单免单"的形式内嵌于售价，不事后兑付、不形成应付负债，因此不设返还专户、无拨备与顺延机制。
2. 步长与 n 均由 r 决定；r 必须按"可分配利润率"口径配置（实付 − 成本 − 税费 − 通道费 − 优惠 − 平台基础运营成本），不得按毛利率配置。类目/单品 r 变更须经财务审核并留版本；阶梯价按订单发生时快照存档，配置变更不追溯已成交订单。
3. **触发仅限本人订单**：周期按**本人类目**复购进度累计，仅本人真实支付（含免单订单）且过售后期的订单计入；不设全局队列、不依赖其他用户订单。
4. 若单笔可分配收益 < 0（尾步低价单），该单不分佣、不入分红池；周期整体盈亏按类目汇总核算。
5. 平台整体收益 = 商品线全周期可分配收益 + 商家服务费 + 流量主广告收益 − 运营成本，按日对账；商品线留存（分佣后平台实收）默认全额进入排队分红池（§4.12）。

### 4.4 单位经济模型（阶梯定价，测算示例）

以 10 元商品为例（r=20%、n=6、步长 2 元；假设综合集采成本 3 元/件、税费+通道费约 6% 按实付计、运营分摊 0.5 元/单）：

| 单序         | 实付        | 商品成本      | 税费+通道费   | 运营分摊     | 可分配收益    | 分佣基数      |
| ---------- | --------- | --------- | -------- | -------- | -------- | --------- |
| 第 1 单（原价）  | 10.00     | 3.00      | 0.60     | 0.50     | 5.90     | 5.90      |
| 第 2 单      | 8.00      | 3.00      | 0.48     | 0.50     | 4.02     | 4.02      |
| 第 3 单      | 6.00      | 3.00      | 0.36     | 0.50     | 2.14     | 2.14      |
| 第 4 单      | 4.00      | 3.00      | 0.24     | 0.50     | 0.26     | 0.26      |
| 第 5 单      | 2.00      | 3.00      | 0.12     | 0.50     | -1.62    | 0         |
| 第 6 单（免单）  | 0.00      | 3.00      | 0.00     | 0.50     | -3.50    | 0         |
| **周期合计**   | **30.00** | **18.00** | **1.80** | **3.00** | **7.20** | **12.32** |

不同利润率档位的阶梯构成（以 10 元商品为例）：

| 可分配利润率 r   | n（单数） | 步长   | 阶梯（元）          | 合计实付  | 名义总额  | 让利比例 |
| ---------- | ----- | ---- | -------------- | ----- | ----- | ---- |
| 20%        | 6     | 2.00 | 10/8/6/4/2/0   | 30.00 | 60.00 | 50%  |
| 25%        | 5     | 2.50 | 10/7.5/5/2.5/0 | 25.00 | 50.00 | 50%  |
| 33.3%（1/3） | 4     | 3.33 | 10/6.7/3.3/0   | 20.00 | 40.00 | 50%  |
| 50%        | 3     | 5.00 | 10/5/0         | 15.00 | 30.00 | 50%  |

结论与运营要求：

1. 全周期让利 50%：用户 n 单共付名义总额的一半（如 6 单付 30 元），累计少付 30 元，其中第 n 单免单 1 件（价值 1 个标价）为核心兑现；第 n+1 单起回到标价循环。
2. **成本红线（10 元商品）**：综合集采成本 ≤4.2 元/件时全周期可分配收益不打穿；≤2.2 元/件时维持 20% 利润口径（周期利润 12 元）。高于 4.2 元触发类目调价或下架评审。
3. 分红池规模：间推关闭时约为分佣基数的 22%（平台服务费 2% + 间推份额 20%）；本例周期入池约 2.7 元。
4. **10 元区 r 配置目标需甲方确认**：按 r=20% 配置即 6 步阶梯（10/8/6/4/2/0，与甲方描述一致），要求集采成本 ≤2.2 元/件；按现行可分配利润率 39%–59% 配置则为 3–4 步（如 10/6.7/3.3/0 或 10/5/0），步数更少、让利比例相同（均为名义的 50%），对应集采成本目标不同（见待确认事项 13）。
5. 以上为测算示例，正式数值以双方确认的财务口径与集采合同为准。

### 4.5 分佣方案（V3.2 修订：收益账户记账结算）

平台采用两套可配置分佣方案，按业务线、场景和生效时间配置，不得叠加生效。分佣基数见 §4.3。

**方案 A：商品复购分佣（默认启用）**

| 角色    | 比例   | 基数   | 说明                                      |
| ----- | ---- | ---- | --------------------------------------- |
| 平台服务费 | 2%   | 分佣基数 | 平台基础服务；默认转入排队分红池（§4.12）                 |
| 团队长   | 8%   | 分佣基数 | 进入团队辅导分红池，按贡献权重分配（公式见 §4.8-5），不按团队人数直接发放 |
| 直推    | 70%  | 分佣基数 | 一级真实有效订单                                |
| 间推    | 20%  | 分佣基数 | 二级服务激励，须合规评审，默认关闭；关闭期间该份额转入排队分红池（§4.12） |
| 合计    | 100% | 分佣基数 | 退款、风控、刷单订单不计                            |

**方案 B：异业联盟商家服务分佣（可配置启用）**

| 角色 | 比例   | 基数   | 说明          |
| -- | ---- | ---- | ----------- |
| 平台 | 10%  | 分佣基数 | 平台服务与运营     |
| 团队 | 10%  | 分佣基数 | 团队辅导分红池     |
| 直推 | 70%  | 分佣基数 | 一级推广关系      |
| 间推 | 10%  | 分佣基数 | 二级服务激励，默认关闭 |
| 合计 | 100% | 分佣基数 | 与方案 A 不可叠加  |

方案 B 基数口径：联盟服务单的分佣基数 = 该单产生的核销服务费 + 券服务费（如有）+ 关联广告收益分成 − 运营成本；联盟线无阶梯返还承诺，不计入商品线周期进度，不产生队位。

**分佣结算方式（V3.2 定稿）**：

1. 订单货款全额归集平台微信商户号，**不使用微信分账通道**（微信服务商分账上限 30%，无法承载本方案比例）。
2. 各角色分佣按单**记账结算**：订单支付成功 → 按分佣基数计算并冻结至各角色收益账户；售后期结束后由结算跑批解冻入余额。
3. 角色收益累计于平台收益账户（余额），可查看累计收益与可用余额；提现走微信"商家转账"打款（限额与规则见 §12.2）。
4. 资金合规由财务侧保障：分佣支出按"平台服务成本"核算，代扣代缴个税后打款；不经任何个人账户中转。

分佣规则：

1. 订单按类型强制路由：实物商品单走方案 A，异业联盟服务单走方案 B，路由字段写入订单表（见 §10.2）。
2. 分佣先冻结，售后期结束后结算入余额。
3. 退款、取消、风控、刷单订单不计分佣，已结算部分按规则回滚（按单独立核算，见 §4.7）。
4. 贡献值不参与分佣现金计算。
5. 团队长收益来自辅导实体店产生的真实广告与消费收益分红权重。
6. 间推关闭期间，其份额实时转入排队分红池；间推开启时归间推，池规模相应下降；配置变更须留版本（§4.12）。

### 4.6 阶梯返还与复购进度规则

1. **阶梯构成**：本类目返还单数 n = ⌈1/r⌉ + 1，步长 = 商品标价 ÷ (n−1)；第 k 单实付 = 标价 − (k−1) × 步长，第 n 单实付 0 元（免单订单）。10 元商品、r=20% 时为 10/8/6/4/2/0。
2. **计算口径统一（V3.2 定稿）**：复购进度**计数按类目**累计；实付价**按目标商品动态计算**——用户某类目第 k 单购买任意商品时，实付 = 该商品标价 − (k−1) × (该商品标价 ÷ (n−1))。文档与页面中的"本类目阶梯价 10/8/6/4/2/0"仅为标价基准商品的示例展示；商品详情、下单页、支付结果页展示的"下一单实付"均按"用户当前步位 + 目标商品标价"实时计算。
3. **触发仅限本人**：按本人类目复购进度累计，仅本人真实支付（含免单订单）且过售后期的订单计入；不设全局队列、不依赖其他用户订单。
4. **周期循环**：第 n 单免单达成后周期重置，第 n+1 单回到商品标价；进度按类目分别累计，跨类目不合并。
5. **系统展示**：复购进度中心与我的返还展示完整阶梯表（各步实付价），当前步高亮、下一单价格突出展示；商品详情与下单页展示"下一单实付 X 元"；支付结果页展示"再买 1 单实付 Y 元"。
6. 零元购（免单）达成时全屏庆祝并推送一次性订阅消息 + 站内消息；我的返还展示**累计返还（累计少付）金额**与历史免单记录。
7. 阶梯价按订单发生时快照存档；类目 r 或标价变更不追溯已成交订单。
8. 平台不承诺现金全额返；返还是以阶梯定价形式内嵌的优惠，不形成应付负债。

### 4.7 退款与周期重置规则

1. 阶梯订单退款按该单实付金额原路退回；退款订单从本类目复购进度中移除。
2. **回退步位边界（V3.2 定稿）**：退款只影响其**后未发生**的步位——退款前已完成并过售后期的低价单**不追差价、不回退重算**；退款单移出进度后，用户下一单按回退后的步位定价。示例：用户已完成第 1–4 单（10/8/6/4 元），第 2 单（8 元）退款，则进度回退至"已完成 2 单"，用户下一单按第 3 步价（6 元）购买；其已购的第 3、4 单价格不调整。
3. **免单订单（pay_type=FREE）默认不支持退款**；因质量等问题确需退款的，退款后本周期作废、进度清零重新累计，防止循环免单；该周期已产生的队位按 §4.12 规则收回，已发放分红从后续收益扣回。免单订单无支付通道可退，退款以补发等值消费余额或下架换货方式执行（口径见待确认事项 17）。
4. 分佣回滚（按单独立核算）：退款订单不计分佣，已结算部分从该用户后续收益中扣回，不足部分挂账并限制提现；该单对应的分红池入账金额同步回滚；**周期不做事后重算**，不影响周期内其他订单的队位与已发分红。
5. 风控订单（刷单等）移出进度并按风控规则处理。
6. 不设返还专户、无拨备与顺延：优惠已内嵌于售价，不存在到期兑付；财务每日输出《分红池监控日报》（§4.12）与分佣对账。

### 4.8 贡献值与季度分红规则（V3.3 按甲方意见修订）

1. 分享一人增加 10 贡献值；贡献值只记权重，不提现、不转让、不构成资产或债权。**贡献分不直接兑付现金**，其价值通过季度分红兑现（见第 4–8 条）；单位参考价值仅作公示（见第 5 条）。
2. 1 贡献值 = 1 权重单位；"以一元为最低对标值"仅作为权重参考刻度，不对应任何现金价值。
3. 用户每日完成广告或站内任务；每月签到不低于 22 天；30 天完成奖励 80 贡献值。未完成活跃要求的用户不计入有效人数（见 §4.10）。
4. **储备专户与季度分红资金链路（V3.3 新增）**：

```text
储备专户划入 = 交易服务费划入 + 广告收益划入（微信流量主分成、商家广告位费用）
             + 其他经合规评审的真实收益划入
当季可分配分红池 = 储备专户当季余额 × 可分配比例（默认 60%，安全系数 0.6，40% 留存缓冲）
每季度计算一次，公示后执行；划入比例与可分配比例后台可配置并留版本。
```

   广告任务的收益直接进入储备专户，形成正循环：用户看广告 → 广告主付费 → 储备增加 → 分红能力增强。"收益放大"放大的是储备，不是承诺。
5. **贡献分单位参考价值（V3.3 新增，合规化改造）**：

```text
贡献分单位参考价值 = 储备专户当季余额 × 0.6 ÷ 有效贡献分权重总量（即流通贡献分总量）
```

   仅作**透明公示、用户可查**，不构成任何直接兑换/兑付承诺；贡献分不可按参考价值直接变现，**兑现唯一通道为季度分红**；不承诺参考价值只涨不跌，但机制透明。举例：储备专户 100 万元、流通贡献分 1000 万分，则每分参考价值 = 100 万 × 0.6 ÷ 1000 万 = 0.06 元；下季度储备到 150 万、流通分未暴增，则上升到 0.09 元。
6. **分红资格三门槛（V3.3 新增，三项同时达标方具备当季分红资格）**：

| 门槛 | 标准（V3.3 建议值，后台可配置） |
| -- | ---- |
| 业绩门槛 | 团队季度真实消费额达标：V1: 5 万；V2: 30 万；V3: 150 万；V4–V6 档位见待确认事项 21 |
| 活跃门槛 | 团队月活跃消费用户占比 ≥15%（活跃消费用户 = 当月完成至少 1 笔有效订单的团队成员） |
| 广告贡献门槛 | 团队辅导的实体店季度广告投放额 ≥ 对应等级要求（后台可配置，档位见待确认事项 22） |

7. **分红公式（唯一口径，V3.3 修订）**：

```text
个人季度分红权重 = 业绩权重 × 60% + 活跃权重 × 25% + 广告贡献权重 × 15%，再乘平台规模系数（封顶 3 倍）
个人季度分红     = 当季可分配分红池 × 个人分红权重 ÷ 全体有效用户分红权重合计
```

   广告收益真正"放大"分红池，但不会因为"人数达标"就多给一份，避免刷人头。
8. 人数仅作权益资格门槛（等级解锁、分红资格），**不进入分红公式**；"人数与业绩双份"机制按资格与荣誉设计：人数达标解锁分红资格、业绩达标参与权重分配，双达标者授予"双达标"荣誉标识及额外权益（非现金翻倍）；是否保留现金双倍需法务出具意见后由甲方决策（见待确认事项）。
9. 贡献值只记权重不兑现；分红按季度发放，总分红不超过当季可分配分红池（储备专户 × 可分配比例）。
10. 平台规模系数按有效用户规模阶梯配置（1000 人 1.0 / 10000 人 1.5 / 100000 人 2.0 / 1000000 人 3.0，建议值，封顶 3 倍），仅影响分红权重，须公示并设上限，不追溯兑付。
11. **团队长辅导分红池权重公式（V3.2 定稿）**：团队长个人权重 = 其名下辅导商家对应期间的分佣基数贡献 × 辅导贡献系数（默认 1.0，后台可配置）；池内按各团队长权重占比分配；层级归属仅按"订单推广关系树上距该单最近的在册团队长"计算，跨两级以上不追溯（与 §16 收益规则一致，法务复核层级口径）。

等级以有效人数作为权益资格参考，不作为计酬依据：

| 等级 | 有效人数      | 权益          |
| -- | --------- | ----------- |
| V1 | 分享 10 人   | 基础推广权益      |
| V2 | 100 人     | 团队视图、基础辅导权益 |
| V3 | 1000 人    | 进阶辅导权益      |
| V4 | 10000 人   | 商家辅导权益      |
| V5 | 100000 人  | 区域联盟权益      |
| V6 | 1000000 人 | 平台战略合作权益    |

1. **商家上传产品资格口径（V3.2 定稿）**：以商家账号绑定的推广团队有效人数 ≥100（V2 档）为资格；资格校验在商品提交时点执行并快照存档，商品审核通过后不受后续人数波动影响。
2. 增款规则（建议）：每新增 100 有效人数增 1 款，须运营审批（见待确认事项）。
3. 等级人数仅作资格参考，不作为现金计酬依据；活跃度要求见 §4.10。

### 4.10 有效人数与活跃度定义（全文档唯一口径）

- **有效人数**：通过推广关系绑定、完成至少 1 笔真实支付（免单订单是否计入"真实支付"口径见待确认事项 20）、已过售后期且无退款、无风控标记的去重用户。
- **活跃度要求**：贡献值获取、等级资格、分红资格均要求用户处于活跃状态——每日完成广告或站内任务、当月签到不低于 22 天；连续 30 天不活跃的用户暂不计入有效人数，恢复活跃后重新计入。
- **活跃快照机制（V3.2 新增）**：系统每日跑批生成用户活跃快照表；分红发放、有效人数统计、规模系数、等级评定等所有结算口径统一以 **T-1 日快照**为准，避免实时计算的性能与口径不一致问题。
- 有效人数用于：等级评定、平台规模系数、团队数据看板、分红权重合计口径，不再另行定义。

粮油食品、健康专区、美容美发、休闲娱乐、五金建材、餐饮美食、酒店民宿。商家入驻须提交营业执照、法人信息、门店照片、类目资质、结算账户和售后承诺；食品类目另需食品经营许可证（见第十二章）。

### 4.12 排队分红规则（平台利润分配）

**定位**：排队分红分配的是平台真实利润（分佣后的平台实收），不是用户货款；阶梯返还按本人复购进度定价（§4.6），排队只作用于分红环节。

**资金来源**：

1. 分红池唯一来源 = 每单分佣后的平台实收：平台服务费（分佣基数 × 2%）+ 间推关闭份额（分佣基数 × 20%；间推开启时该份额归间推、不入池）。
2. 分红池独立核算、专项用于排队分红发放，与用户货款、商家服务费严格隔离；池内余额每日在"我的分红"页公示。

**入队与队位**：

1. 用户每完成 1 个返还周期（累计完成 n 单并达成免单）获得 1 个队位；多个周期可累积多个队位。
2. 队位只按**完成返还周期的时间**排序；推广关系、团队人数、贡献值、等级一律不影响队位顺序与金额（不按人头计酬）。
3. 退款导致周期不成立的（含免单订单退款，见 §4.7），收回该周期产生的队位；已发放分红从该用户后续收益中扣回。

**发放规则（默认参数，全部后台可配置）**：

1. 每日 00:00 发放 1 次；单日发放总额 = 分红池当日余额 × 发放比例（默认 5%）。
2. 当日从队首起按队位完成时间顺序发放，默认每日最多发放 100 个队位（可配置）；每席金额 = 单日发放总额 ÷ 当日实际发放席数；同一用户同日多个队位仅结算 1 个，其余队位保留参与后续日期。
3. **跑批事务口径（V3.2 定稿）**：跑批先自队首逐席完成活跃校验（以 T-1 日活跃快照为准，§4.10），得出"当日实际发放名单"；再以名单席数计算每席金额；名单生成、金额计算、发放记账在**单个事务**内完成；被跳过的席当日不计入席数，其应发份额留存池内顺延。
4. 活跃校验：结算时用户须处于活跃状态（当日完成广告或站内任务 + 当月签到 ≥22 天）；不活跃则跳过该队位当日结算、顺延至后续日期，队位不取消。
5. 池内余额不足以覆盖当日应发时，按队列顺序发完即止，剩余留存池内顺延至下一日并公示；顺延超过 7 天触发财务专项处置。
6. 分红默认进入平台消费余额（默认不可提现）；累计发放不超过池内实际到账金额；平台不承诺分红金额、不承诺到账时间、不保本。

**与季度分红的关系**：

1. 排队分红与季度分红两条线并存、独立核算：排队分红来源于商品线分佣后平台实收，按完成周期时间排队发放；季度分红来源于储备专户（§4.8-4，划入平台真实收益），按三门槛资格与业绩/活跃/广告贡献权重（60/25/15）发放。

**合规护栏（写入规则页、客服话术与审核材料）**：

1. 只分平台真实利润，绝不动用用户货款——这是与"排队返利"（以后到用户资金返先到用户）的本质区别；
2. 队位只按完成返还周期的时间排序，推广关系、人数、贡献值一律不计入；
3. 不承诺分红金额与到账时间，池内不足顺延并公示；
4. 默认进入消费余额、不可提现；上线前完成法务专项评审（§12.5）。

## 八、广告体系与收益结算（V3.2 新增）

### 8.1 广告能力边界与选型

1. **微信流量主广告组件**（主方案）：小程序累计独立访客（UV）≥1000 且无违规后可开通流量主，接入激励视频、插屏、Banner 广告组件；激励视频通过 `onClose(isEnded)` 回调判定完整观看，作为"广告任务完成"依据。
2. **站内任务系统**（冷启动替代）：流量主开通前及非广告日，用户通过每日签到、浏览商品（≥15 秒）、分享等站内任务获取贡献值与活跃度；任务类型、奖励值后台可配置。
3. **第三方广告联盟**：微信小程序内不可运行第三方联盟 JS SDK；如有外部联盟合作需求，以 Web-view 跳转 H5 形式承接（体验与审核受限），作为备选不纳入首期。

### 8.2 任务与收益规则

1. 每日任务组合（可配置）：签到（+N 贡献值）、广告任务或站内浏览任务（+N 贡献值，计入当日活跃）；每月签到 ≥22 天为活跃门槛。
2. 30 天连续完成奖励 80 贡献值（§4.8）。
3. 广告任务完成判定以服务端收到微信流量主回调 + 用户端完成上报双校验为准，防伪造。
4. 流量主广告分成收益按微信结算周期入账，计入平台真实收益（§4.2），并按划入比例进入**季度分红储备专户**（§4.8-4），与贡献分价值形成正循环。

### 8.3 结算与对账

1. 流量主收益：按微信后台结算单人工/接口导入对账，日终与平台账核对。
2. 商家广告位：按档期与曝光/点击/核销数据出结算单（§6.2）。
3. 广告事件（曝光、点击、完成）全量落库，支持风控防刷审计与 eCPM 看板（§14）。

## 九、核心流程设计

### 9.1 下单—支付—阶梯进度—免单流程

1. 用户选择商品下单（页面展示按当前进度动态生成的阶梯表与下一单实付）。
2. 支付成功后生成订单，按阶梯价计实付，计入本人类目复购进度；阶梯价快照存档。
3. 到达第 n 步时，下单入口转为"领取免单"：用户点击 → 服务端校验（步位、风控、周期真实性）→ 生成**免单订单**（pay_type=FREE，状态直接为已支付/待发货，自建免单流水号，不走支付通道）→ 全屏庆祝 + 订阅消息授权引导 + 站内消息。
4. 免单达成后周期重置，第 n+1 单回到标价。
5. 我的返还/复购进度中心展示累计返还与阶梯表。
6. 退款订单移出进度，按 §4.7 回退步位规则处理；免单订单默认不退款，特殊退款则周期作废、进度清零。
7. 分佣按单记账（基数为该单可分配收益、不为负，冻结→售后期后结算入收益账户），平台实收进入排队分红池（§4.12）。

### 9.2 推广关系流程

1. 用户生成推广二维码（小程序码携带场景值，防篡改）。
2. 新用户扫码首次绑定直推关系；**默认规则：首绑即锁、不可转让、不可变更**；设备/IP 异常时冻结待人工审核，设申诉通道。
3. 直推用户真实消费产生分佣记账（按订单类型走方案 A/B）；间推按配置产生服务激励，默认关闭。
4. 我的团队展示直推、间推（关闭时隐藏）、有效人数、贡献值权重、辅导商家。
5. 推广收益冻结—结算入余额—提现（代扣税、商家转账）；贡献分不可提现。

### 9.3 商家联盟与广告任务流程

1. 商家入驻审核，定位门店，选择类目。
2. 创建优惠券，设置库存、有效期、核销规则。
3. 申请/购买广告位，上传素材，平台审核。
4. 用户完成每日任务：签到、广告任务（流量主开通后）或站内浏览任务；每月签到不低于 22 天，30 天完成奖励 80 贡献值。
5. 流量主广告分成与商家广告位费用进入平台真实收益，按规则分佣和对账。

### 9.4 贡献值与季度分红流程

1. 分享一人增加 10 贡献值，仅记权重不兑现金。
2. 储备专户划入：交易服务费、广告收益（微信流量主分成、商家广告位费用）按划入比例划入；每季度按可分配比例（默认 60%）计算当季可分配分红池，公示后执行（§4.8-4）。
3. 季度分红资格核算跑批：业绩门槛（团队季度真实消费额）、活跃门槛（团队月活跃消费用户占比 ≥15%）、广告贡献门槛（辅导实体店季度广告投放额）三门槛同时达标方具资格；以季度业绩数据与 T-1 日活跃快照为准，核算结果生成资格快照存档。
4. 分红权重 = 业绩权重 × 60% + 活跃权重 × 25% + 广告贡献权重 × 15%，再乘规模系数；总分红不超过当季可分配分红池；人数仅作资格门槛。
5. 贡献分单位参考价值每季度公示（储备 × 0.6 ÷ 流通贡献分总量），仅作参考、不兑付；分红发放推送一次性订阅消息（已授权用户）+ 站内消息。

### 9.5 排队分红流程

1. 每单分佣结算后，平台实收（平台服务费 + 间推关闭份额）实时进入排队分红池（§4.3）。
2. 用户完成返还周期（累计 n 单并达成免单）获得 1 个队位，按完成时间入队。
3. 每日 00:00 跑批（单事务，§4.12-3）：活跃校验得出当日实际发放名单 → 单日总额 = 池当日余额 × 5%（默认）→ 每席均分 → 发放至消费余额。
4. 活跃校验以 T-1 日快照 + 当日签到/任务数据为准；不活跃跳过、顺延至后续日期。
5. 发放后推送一次性订阅消息（已授权用户）+ 站内消息；池内不足顺延公示，超 7 天财务专项处置。
6. 退款导致周期不成立的收回队位；已发分红从该用户后续收益扣回（§4.7）。
7. 财务每日输出《分红池监控日报》（余额、入池、发放、顺延、队位规模、挪用告警）。

### 9.6 异常场景处理

| 场景           | 处理                               |
| ------------ | -------------------------------- |
| 支付重复回调       | 幂等校验，不重复生成订单/进度/分佣               |
| 免单重复领取/并发领取   | 步位行级锁 + 领取接口幂等键，重复请求返回已有免单订单 |
| 免单领取校验失败     | 明确返回原因（步位不足/风控/周期异常），可申诉 |
| 阶梯订单退款       | 按实付原路退；移出进度、按 §4.7 回退步位；分佣与入池按单回滚（周期不重算） |
| 免单订单退款      | 默认不支持；确需退款的周期作废、进度清零、队位收回、已发分红扣回；以消费余额补发或换货执行 |
| 商家转账用户未确认收款  | 提醒（订阅消息+站内），超时自动退回余额并重发 |
| 进度异常         | 后台可人工重排，记录审计                     |
| 阶梯价配置变更      | 按订单快照价执行，不追溯；配置变更留版本             |
| 分红池余额不足      | 当日发完即止、顺延公示，超 7 天财务专项处置          |
| 同一用户多队位同日结算  | 同日仅结算 1 个队位，其余保留后续日期             |
| 分佣回滚         | 退款/风控订单分佣回滚，已结算部分从后续收益扣回         |
| 提现失败         | 打款失败重试，超时转人工                     |
| 广告回调伪造       | 服务端验签、防刷、黑名单、结算复核                |
| 商家重复核销       | 核销码唯一，防重复核销                      |
| 低价单（可分配收益为负） | 该单不计分佣、不入分红池，周期整体按类目汇总核算         |
| 审核期降级开关开启    | 分红/团队入口隐藏，规则页降级为阶梯优惠说明，资金侧照常记账 |

## 十二、小程序资质与第三方对接规划

### 12.1 账号与主体

1. 小程序矩阵：用户端小程序（主端，电商类目）+ 商家端小程序（独立注册，服务类目）+ 运营后台（Web，企业主体）。
2. 主体：企业主体（非个人），完成微信认证、ICP 备案。
3. 类目资质：电商平台/商家自营类目；涉及粮油食品需食品经营许可证；撮合商家交易可能涉及 EDI 许可，由法务评估后确认（见待确认事项）。
4. 隐私合规：管理后台配置《用户隐私保护指引》，最小化授权、拒绝追踪、未成年人保护。

### 12.2 微信支付与资金通道（V3.2 重写）

1. 申请微信支付商户号，开通 JSAPI 支付（WX_PAY 订单）。
2. **分佣结算**：不使用微信分账（上限 30%）。货款全额归集平台商户号，分佣按单记账至收益账户，售后期后结算入余额（§4.5）。
3. **提现打款**：微信"商家转账"产品（分销返佣场景），硬性约束如下，须写入财务对账方案与用户协议：
   - 开通门槛：企业主体、入驻满 90 天且近 30 天连续健康交易、场景资料审核；
   - 限额：单笔约 500 元上限、单日向单用户 2000 元上限（以商户核准为准，开通后可申请调整）；
   - 需用户主动确认收款才入账，系统提供确认收款引导与超时退回重发；
   - 每笔转账按场景备注真实背景信息。
4. **上线节奏影响（需甲方知晓）**：商家转账预计在支付跑通约 3 个月后开通；上线初期用户收益正常累计、提现通道后开，规则页需前置说明。
5. 费率、结算周期写入财务对账方案；免单订单不产生支付通道费，单独对账。

### 12.3 消息推送（V3.2 重写）

1. 一次性订阅消息（电商类目仅有此能力）：免单达成、提现结果等关键节点，在用户下单/领取免单/申请提现等主动行为时请求授权。
2. 站内消息中心（兜底主通道）：队位获得、分红发放、分红顺延、降价提醒、系统公告等全部落站内消息，红点提醒。
3. 模板 ID 统一管理，文案过法务（不得出现"保本""全额返""排队返利"等表述）。

### 12.4 其他第三方服务

1. 地图：腾讯地图/微信地图 SDK，门店定位与距离排序。
2. 存储/CDN：商品图、资质文件、广告素材 OSS + CDN。
3. 内容安全：商家上传图文接入微信内容安全接口（文本/图片审核）。
4. 物流：商家自发货或平台集采代发，接入快递查询。
5. 客服：微信客服会话按钮 + 平台工单系统。
6. 广告：微信流量主（§8.1）。

### 12.5 小程序审核预案（V3.2 增强）

1. 阶梯定价/分销/排队分红均为微信审核高危模式，提交审核时附《模式说明函》《资金链路图》——阶梯为价格内嵌优惠（无专户、无兑付、无资金池），分红池单独一条资金线（只分平台已实现利润）。
2. 排队分红上线前须完成法务专项评审；预备答复口径：阶梯返还是售价递减、不依赖他人订单（本人复购进度口径）；分红只分平台已实现利润（排队分红只分分佣后平台实收，季度分红只分储备专户内划入的平台真实收益）；贡献分不直接兑付现金，仅有透明公示的参考价值，兑现唯一通道为季度分红；队位只按完成返还周期的时间排序；不承诺金额与到账时间。
3. **分批提审策略（新增）**：首批提审仅包含"电商 + 阶梯优惠"主链路；"我的分红""我的团队"模块在首批过审后第二批次迭代上线。
4. **前端功能开关（新增）**：审核降级开关存于后台系统开关配置表，前端按配置渲染——开关开启时整体隐藏分红/团队入口、规则页降级为阶梯优惠说明；资金侧（记账、入池、排队）照常运行，不受前端展示影响。
5. 降级方案预设：间推默认关闭、排队分红暂停发放开关（池内资金留存、已排队位保留）、规则页前置确认。
6. 预留审核沟通与申诉通道，法务参与应答。

## 十三、非功能需求

1. 性能：首页 P95<1.5s，支付回调<500ms，返还/进度查询<800ms。
2. 安全：HTTPS、支付签名、接口幂等、越权校验、敏感字段加密、操作审计；免单领取接口幂等键 + 步位行级锁。
3. 隐私：最小化授权、隐私政策、广告组件授权、拒绝追踪、未成年人保护。
4. 可用性：核心链路 99.9%，支付/分佣/免单/分红每日对账跑批。

## 十五、合规与风险控制

1. 返利合规：阶梯定价、第 n 单免单；不承诺全额返、不承诺保本、不形成资金池；优惠内嵌于售价、不形成应付返利负债，无兑付与顺延风险；阶梯参数后台配置并留版本。
2. 多级分销：直推 70%、间推 20%/10% 须经合规评审；间推仅服务激励，不按人数计酬，可配置关闭且默认关闭；禁止收入门费；团队长辅导分红池按 §4.8-9 层级归属口径执行（法务复核）。
3. 分佣结算：收益账户记账结算制，分佣支出按平台服务成本核算、代扣代缴个税；不经个人账户中转；提现走商家转账并遵守其限额规则。
4. 贡献值：只记权重不兑现、不提现、不转让、不形成债务；规模系数仅影响分红权重并公示封顶。
5. 人数考核：人数只作权益资格和运营参考，不作计酬依据；分红公式仅含业绩、活跃、广告贡献三类权重（业绩 60%/活跃 25%/广告贡献 15%，§4.8-7），人数不进入权重。
6. 分红（季度）：资金来源为储备专户（仅划入平台真实收益），按季度计算、公示后发放，总分红不超过当季可分配分红池（储备专户余额 × 可分配比例）；"双达标"为资格与荣誉，非现金翻倍（待甲方确认）。
7. 广告：真实任务、非诱导点击、服务端验签、防刷、隐私授权；广告能力限于微信流量主组件与站内任务（§8.1）。
8. 提现：实名、税务代扣、风控、限额、审核、拆笔；贡献分不可提现；分红默认不可提现。
9. 商家：资质、价格、质量、售后、禁售品审核；团队 100 人上传产品仅资格（提交时点快照），需平台审核。
10. 宣传口径：禁用"排队返利""保本""全额返"表述；阶梯价宣传须与后台配置一致，须明示"按本人复购进度累计"，不得暗示他人订单可加速；排队分红对外统一按"平台利润分红"口径描述，不得宣传为"排队领钱"；所有物料过法务。
11. 规则透明：规则版本化，用户下单前确认"我已阅读"，保留免责声明和客服工单。
12. **排队分红护栏**：只分平台真实利润，绝不动用用户货款；队位只按完成返还周期的时间排序，推广关系、人数、贡献值不计入；不承诺分红金额与到账时间，池内不足顺延公示；默认消费余额、不可提现；上线前完成法务专项评审（§12.5）。
13. **储备专户与贡献分护栏（V3.3 新增）**：储备专户仅划入平台真实收益，与用户货款、商家结算款严格隔离；贡献分不直接兑付现金、不可转让、不可交易，单位参考价值仅作公示、不构成兑换承诺、不承诺只涨不跌；季度分红为贡献分价值的唯一兑现通道；公示口径与计算记录留档可审计；上线前随 §12.5 法务专项评审一并出具意见。

## 十六、团队长与推广运营制度

1. 团队长准入：等级 V2 及以上，或连续两季度真实业绩达标。
2. 辅导动作清单：拓展实体商家、辅导复购、规则宣导、异常反馈。
3. 考核：按季度考核所辅导商家产生的真实广告与消费收益（季度分红的广告贡献门槛即"团队辅导实体店季度广告投放额"，见 §4.8-6）；未达标降级或取消资格。
4. **收益（V3.2 补全公式）**：进入团队辅导分红池（方案 A 8% / 方案 B 10%）；团队长个人权重 = 其名下辅导商家对应期间的分佣基数贡献 × 辅导贡献系数（默认 1.0，后台可配置）；池内按权重占比分配，不按人数发放；层级归属按"距该单最近的在册团队长"，跨两级以上不追溯（§4.8-9）。
5. 退出与冻结：违规（刷单、虚假宣传、拉人头收费）即冻结收益并移交风控调查。

## 十八、验收标准

1. 用户可完成首页—商品—下单—支付—阶梯进度—免单领取—复购全链路；免单订单不走支付通道、带免单标识与自建流水。
2. 阶梯价正确：第 k 单实付 = 标价 −(k−1)×步长，第 n 单免单；进度按类目计数、实付按商品动态计算；10 元/r=20% 类目为 10/8/6/4/2/0；周期达成后第 n+1 单回到标价。
3. 我的返还、复购进度中心、复购中心阶梯数据一致；商品详情/下单页/支付结果页"下一单实付"与"用户当前步位 + 商品标价"动态计算结果一致。
4. 分佣按单可分配收益记账结算（不为负），冻结→结算→余额链路完整；退款/风控不计并按单回滚；方案 A 与方案 B 按订单类型路由且不可叠加。
5. 日终三本账：微信支付流水（及免单自建流水）与订单一致；分佣基数合计 = 各单可分配收益（不为负）合计；阶梯价快照与成交订单一致；分红池入账 = 平台实收合计。
6. 退款按 §4.7 回退步位（仅影响其后未发生步位）；免单订单默认不可退款，特殊退款周期作废、进度清零、队位收回、已发分红扣回。
7. 推广二维码绑定、团队、推广收益、提现可用；提现走商家转账，拆笔、确认收款、超时退回重发逻辑正确；贡献分不可提现；分红默认不可提现。
8. 商家入驻、定位、发券、广告位、商品上传（资格提交时点快照）、核销、对账可用。
9. 站内任务与广告任务完成判定可验签、可对账、可防刷；流量主开关与 UV 门槛逻辑正确。
10. 消息中心全量可用；一次性订阅消息授权链路正确；审核降级开关开启后分红/团队入口隐藏、规则页降级。
11. 后台系统设置、规则版本、阶梯参数配置、分红池管理、收益账户管理、风控、审计可用。
12. 规则说明包含免责声明、阶梯规则与排队分红说明；用户首次下单需确认。
13. 通过合规评审和财务对账测试。
14. **排队分红**：队位按完成返还周期时间排序并正确发放/收回；每日发放（单事务、活跃快照口径）、同日单队位结算、池内不足顺延逻辑正确；余额公示与发放记录可查。
15. **季度分红与储备专户（V3.3）**：储备专户划入（交易服务费/广告收益/其他）与划出流水完整、可对账；季度可分配分红池 = 储备余额 × 可分配比例（默认 60%）计算正确并公示；三门槛资格核算正确并生成资格快照；分红权重 = 业绩×60% + 活跃×25% + 广告贡献×15%（×规模系数）计算正确；贡献分单位参考价值公示值与公式一致且无兑付入口。

## 二十一、一句话总结

本方案以"按类目可分配利润率动态设计阶梯价（n = ⌈1/r⌉+1 单、步长 = 标价 ÷(n−1)、第 n 单免单）—个人复购进度—周期循环"为用户主线，以"异业联盟商家券/广告位 + 微信流量主与站内任务"为收益来源，以"阶梯价即返还（无专户、无兑付）+ 分佣收益账户记账结算（提现走商家转账）+ 平台实收排队分红 + 储备专户季度分红（业绩 60%/活跃 25%/广告贡献 15%，贡献分参考价值透明公示、仅经分红兑现）"为资金规则，同时把"不承诺全额返、不形成资金池、优惠内嵌售价、队位只按完成周期时间排序、贡献分不直接兑付、人数不计酬、间推可关闭"作为合规底线；商品线承担获客与复购职能，广告收益经储备专户放大平台分红能力，平台盈利依靠广告收益与商家服务费。
