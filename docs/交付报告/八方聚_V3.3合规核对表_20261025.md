1. **免单退款未扣回已发分红**（§4.7-3 / §4.12-3 / §18-6）：`revokeSlotsByPeriod` 现在同时收回已发放的队位，并把已发分红从分红余额→可用余额→挂账依次扣回，回补分红池、写审计。
2. **分享 +10 贡献值缺失**（§4.8-1）：`bindReferral` 成功绑定后给邀请人 +10 权重并写 `contributionFlows`。
3. **退款不真退钱**（§4.7-1 / §12.2）：新增 `wxpayProvider.refund`（v3 `/v3/refund/domestic/refunds`，`out_refund_no=RF_<orderId>` 幂等），后台退款与售后受理都改为**先退款成功再落本地状态**，失败则整单不动；mock 模式仍只改本地。
4. **回调金额未校验**（§18-5）：`notify-wx` 增加金额一致性校验（`resource.amount.total` vs 订单 `paidFen`）、未知订单拒绝、已退款/已取消订单的迟到回调忽略。
5. **等级与有效人数缺失**（§4.9 / §4.10）：新增 `domain/level.js`（V1–V6 门槛与权益）、`svc.validUserCount`（直推+间推两层；真实支付且过售后期、无退款/售后中、非黑名单、近 30 天活跃）、`svc.levelProfile`，并提供 `GET /api/user/level`；个人中心与「我的团队」展示等级、有效人数与下一档进度。
6. **支付结果页与免单领取页缺失**（§5.1 / §4.6-5/6）：新增 `pages/pay-result`（本单实付/步位 + 再买一单实付 + 免单进度 + 继续支付）与 `pages/free-claim`（步位校验 → 领取免单 → 全屏庆祝 → 一次性订阅授权）；商品页支付成功与订单页付款后均跳转结果页。

### 需要甲方拍板（1 项）

- **分佣基数口径**：文档 §4.3/§18-5 是"每单 max(0, 可分配)"（示例 12.32 元），但同页 §4.4 的可分配只有 7.20 元——按文档会**超发 5.12 元/周期**。当前实现改为"周期可分配 × 系数（≤1）× 90%"，周期分佣基数 6.46 元、平台留存 0.74 元。这一改动直接降低推广人收益约 48%，**必须书面向甲方确认**（`commissionPlatformRetainRate` 可配为 0 回到"周期全额分配"，但仍是周期口径）。
