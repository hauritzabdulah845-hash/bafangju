## 第二步 · 上传证书文件到服务器

网页终端工具栏一般有 **「上传文件」** 图标（或右键菜单 / 直接拖拽文件进终端窗口）。把这两个文件传上去：

```
G:\八方聚共享平台\开发文档\SSL证书\www.bfjzs.com_nginx\www.bfjzs.com_bundle.crt
G:\八方聚共享平台\开发文档\SSL证书\www.bfjzs.com_nginx\www.bfjzs.com.key
```

**上传后确认文件在哪**（网页终端执行）：
```bash
ls -la ~/ | grep -E 'bfjzs|\.crt|\.key'
```
能看到 `www.bfjzs.com_bundle.crt` 和 `www.bfjzs.com.key` 即可。

> **没有上传按钮？** 用粘贴方式——在本地用记事本打开这两个文件，全选复制，在网页终端执行（把"粘贴内容"替换为文件全文，含 `-----BEGIN...-----` 行）：
> 用 `ubuntu` 用户写 `/etc/` 需要 sudo，`cat` 直接重定向会 Permission denied，所以这里用 `sudo tee`（整段粘贴，注意 `PEM`/`KEY` 单独成行）：
> ```bash
> sudo mkdir -p /etc/nginx/ssl
> sudo tee /etc/nginx/ssl/bfjzs.com.pem >/dev/null <<'PEM'
> 粘贴 bundle.crt 的全部内容
> PEM
> sudo tee /etc/nginx/ssl/bfjzs.com.key >/dev/null <<'KEY'
> 粘贴 .key 的全部内容
> KEY
> sudo chmod 600 /etc/nginx/ssl/bfjzs.com.key
> ls -la /etc/nginx/ssl/
> ```
> 用这个粘贴方式的话，**第三步可以跳过**（文件已放好），直接做第四步。

## 第三步 · 改名并放到 nginx 目录 + 备份

> ⚠️ **重要**：网页终端登录的是 `ubuntu` 用户（提示符 `ubuntu@VM-...:~$`），写 `/etc/` 需要 `sudo`。之前不带 sudo 的 `mv` 会静默失败——这正是证书没进 `/etc/nginx/ssl/` 的原因。以下命令**全部带 sudo**。

**一条命令自动找证书链 + 安装（整段粘贴；find 只有单个 -name，不会被网页终端转义破坏）：**
```bash
echo "===找证书链==="; sudo find /home/ubuntu /root -name '*.crt' 2>/dev/null
CERT=$(sudo find /home/ubuntu /root -name '*.crt' 2>/dev/null | head -1)
echo "证书链=[$CERT]"
sudo cp "$CERT" /etc/nginx/ssl/bfjzs.com.pem
sudo chmod 600 /etc/nginx/ssl/bfjzs.com.key
ls -la /etc/nginx/ssl/
```
> ⚠️ 不要用带 `\(` `\)` 的 find 命令——网页终端复制时会把 `\(` 转成 `$` 导致语法错误。上面的 find 只有一个 `-name`，安全。
>
> 若 `证书链=[]` 为空 → 说明证书链文件根本没上传成功，用第二步末尾的 `sudo tee` 粘贴方式把 `www.bfjzs.com_bundle.crt` 全文贴进去，或用上传功能重新传这个文件（7KB 那个）。

**切换前备份现网配置（回滚用）：**

## HTTPS 没通？执行这段一次性诊断（把输出发我）

在网页终端**整段粘贴**执行，会一次性打印所有关键信息：
```bash
echo "===证书文件==="; ls -la /etc/nginx/ssl/ 2>&1
echo "===nginx配置listen/ssl==="; grep -nE 'listen|ssl_certificate|server_name' /etc/nginx/conf.d/bafangju.conf 2>&1
echo "===nginx语法==="; nginx -t 2>&1
echo "===监听端口==="; ss -tlnp 2>/dev/null | grep -E ':80 |:443 ' || netstat -tlnp 2>/dev/null | grep -E ':80 |:443 '
echo "===deploy脚本==="; ls -la /opt/bafangju/scripts/deploy.sh 2>&1
```
把打印结果全部截图发我。看这份输出能一次判断：证书在不在/名字对不对、nginx 有没有配 443、语法是否通过、443 有没有被监听。

另外**再确认一遍防火墙**：控制台 → 轻量服务器 → 防火墙，必须有 `TCP 443 来源 0.0.0.0/0` 这条规则（80 已通但 443 连不上，很可能就是这条没加）。

## 卡住了怎么办

把网页终端**报错的那几行截图**发我，我帮你判断。常见卡点：
- 「登录」没反应 / 要密码 → 腾讯云「重置密码」后重试
- 没有上传按钮 → 用第二步末尾的 `cat` 粘贴方式
- 证书内容粘贴报错 → 确认内容包含完整 `-----BEGIN----` 到 `-----END----` 行，无多余空格
- `mv` 报 `No such file` → 用 `ls -la ~/` 看上传后的真实文件名，替换命令里的文件名
