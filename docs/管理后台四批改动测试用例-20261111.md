# 八方聚管理后台 · 四批改动测试用例

- 文档版本：v1.0
- 编写日期：2026-11-11
- 覆盖范围：管理后台 P0 / P1 / P2 / P3 四批改动 + 关联后端接口 + 小程序端回归
- 被测对象：`bafangju-server/public/admin.html` 及配套 `public/css/*`、`public/js/*`、`src/domain/ops.js`
- 执行方式：部署到服务器后执行（本机无 Node，无法本地跑 `npm test`）

## 一、测试环境与准备

### 1.1 环境

| 项目 | 要求 |
|------|------|
| 后台地址 | `https://<服务器域名>/admin.html` |
| 浏览器 | Chrome / Edge 最新版；另需 1 台 1366×768 笔记本做窄屏验证 |
| 账号 A | 总账号（`super`，全部权限） |
| 账号 B | 子管理员，仅勾选「商品管理 + 订单管理」 |
| 小程序 | 用户端、商家端各 1 个体验版，用于回归首页运营帧与「赚实惠」页 |

### 1.2 部署与自动测试

```bash
cd bafangju-server
npm test
pm2 restart bafangju   # 或你们的进程管理命令
```

**预期**：`npm test` 全绿，新增的违规词回归用例（`test/ops-content.test.js`）通过。

### 1.3 测试数据准备

| 数据 | 准备方式 | 用途 |
|------|----------|------|
| 待审商品 ≥ 1 条 | 商家端提交 1 个商品 | 看板待审商品 / 角标 / 商品审核 |
| 待审入驻申请 ≥ 1 条 | 小程序商家入驻提交 | 入驻资质表 / 入驻审核 |
| 待审提现单 ≥ 1 条 | 用户端发起提现 | 提现审核 / 待办 |
| 广告计划 ≥ 1 条（草稿 + 投放中各 1） | 广告中心新建 | 广告计划表 / 审核 / 结算 |
| 运营帧文案含「返利」 | 内容与运营 → 新增运营帧 | 违规词拦截 |
| 空数据环境 | 测试库清空某类数据，或用无权限子账号 | 空状态验证 |

### 1.4 结果填写约定

- 结论列填 `通过 / 不通过 / 阻塞 / 不适用`
- 不通过必须附：截图 + 浏览器 Console 报错 + 复现步骤
